# 王美丽 · 个人主页

这是我（王美丽，毕业于北京大学）的个人主页源代码，使用 **GitHub Pages** 免费发布。

网站地址：<https://wangxiaoqin00766-jpg.github.io/>

## 仓库里都有什么

| 文件 | 作用 |
| --- | --- |
| `index.html` | 主页内容：文字、标题、链接都写在这里 |
| `styles.css` | 外观样式：颜色、字号、间距 |
| `avatar.svg` | 首屏头像（原创水豚形象，矢量图，可无损放大） |
| `og.jpg` | 分享到微信、微博等平台时的预览大图 |
| `404.html` | 访问不存在的网址时显示的页面 |
| `favicon.svg` | 浏览器标签页上的小图标 |
| `.nojekyll` | 告诉 GitHub Pages 不要额外处理文件（照原样发布） |

## 怎么修改内容

在 GitHub 网页上点开文件，右上角点铅笔图标即可直接编辑，改完点 **Commit changes**，网站大约 1 分钟后自动更新。

最常改的几处：

1. **换头像照片**：把照片命名为 `avatar.jpg` 上传到本仓库，然后在 `index.html` 里按注释提示，把水豚头像换成照片。
   （想直接改水豚的样子，编辑 `avatar.svg` 即可——它就是个纯文本文件，所有形状都是可读的坐标。）
2. **补充教育信息**：在 `index.html` 的「教育背景」一段，取消注释并填写专业、学位、毕业年份。
3. **加上邮箱**：在 `index.html` 的「联系我」一段，取消注释并填写自己的邮箱。
4. **换配色**：在 `styles.css` 最上面的 `:root` 里，改 `--brand` 和 `--accent` 两个颜色即可。

## 技术说明

- 纯静态页面，只用 HTML + CSS，没有任何依赖，也不需要构建步骤。
- 自适应手机、平板和电脑屏幕。
- 会自动跟随系统的浅色 / 深色模式。
- 无 JavaScript、无第三方请求，加载快，也不收集任何访客数据。
